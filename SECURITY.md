# Security Policy

## Supported Versions

Until the first public release, only the pre-CalVer `main` branch is supported
for security fixes. Tagged releases will be added to this table after the first
public CalVer release.

| Version | Supported |
| --- | --- |
| pre-CalVer `main` | Yes |
| older branches | No |

## Reporting

Report security issues by email:

```text
diego.resendez@zero-oneit.com
```

Do not open public issues for vulnerabilities.

## PGP

Encrypted security mail is not available yet. If you need to send sensitive
details before a PGP key is published, send a short initial report first and
coordinate a safer channel with the maintainer.

## Response Timeline

- Acknowledge receipt within 3 business days.
- Provide an initial triage response within 7 business days.
- Coordinate a remediation and disclosure timeline based on severity and
  release impact.

## Coordinated Disclosure

Do not publish exploit details, proof of concept code, or vulnerability writeups
before the maintainer confirms receipt and a remediation window. Public
disclosure should happen only after a fix, mitigation, or documented no-fix
decision is available.
