# NightBridge 26.5.0 Alpha Is Live

NightBridge `26.5.0-alpha` is published as a GitHub pre-release:

https://github.com/NightBridgeHQ/nightbridge/releases/tag/26.5.0-alpha

This alpha is focused on the headless LocalSend-compatible server path:

- official LocalSend apps can send to a NightBridge daemon on a server, NAS,
  Raspberry Pi, homelab box, or always-on workstation
- operators can manage receive policy, pending peers, inbox state, and sends
  through the CLI, short `nbrg` alias, TUI, and daemon API
- Linux and macOS server tarballs, a direct Debian package asset, SBOM,
  checksums, and `install.sh` are attached to the release
- Native Mesh LAN is included as an advanced preview for trusted NightBridge
  daemons on the same network

Install the pinned alpha:

```bash
curl -fsSL https://raw.githubusercontent.com/NightBridgeHQ/nightbridge/main/install.sh | \
  sh -s -- --version 26.5.0-alpha
```

The published installer smoke passed on 2026-05-28: it downloaded the macOS
arm64 tarball, verified `SHA256SUMS`, installed all four binaries into a
temporary directory, and `night-bridge --help` ran successfully.

Production distribution channels remain deferred for this alpha, including
APT/PPA, Homebrew, RPM, production desktop signing/notarization, and strict GUI
WebDriver coverage.
